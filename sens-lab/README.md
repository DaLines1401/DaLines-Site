# DaLines Sens Lab · Portable for Windows

แอปฝึกเล็ง 3D และช่วยหา Sens สำหรับ Valorant, Counter-Strike 2 และ Apex Legends รุ่นทดลอง 0.1.0 แนวการใช้งานได้รับแรงบันดาลใจจาก sensitivity finder ของ Oblivity โดยพัฒนาโค้ดและสนามเอง ไม่ใช่โปรแกรมหรืออัลกอริทึมของ Oblivity

## เปิดใช้งานและส่งให้เพื่อน

1. แตก ZIP ทั้งหมดไว้ในโฟลเดอร์ที่เขียนไฟล์ได้ เช่น Downloads หรือ Documents
2. เปิด **DaLines Sens Lab.exe** โดยเก็บไฟล์อื่น ๆ ในโฟลเดอร์ไว้ครบ
3. ตั้ง DPI ให้ตรงกับเมาส์ ใส่ Sens และ FOV ในเกมที่ใช้อยู่
4. ฝึกอิสระ 2–3 รอบ แล้วกด **เริ่มค้นหา Sens** และ **เริ่มรอบนี้**
5. อ่านผลวิเคราะห์หลังฝึกครบ แล้วนำค่า Hipfire ไปลองในเกมจริง

ใช้เมาส์เพื่อหมุนกล้อง คลิกซ้ายเพื่อยิงในโหมด Flick ส่วน Tracking ให้เล็งตามเป้าโดยไม่ต้องคลิก กด Esc เพื่อพักและเริ่มรอบปัจจุบันใหม่ กด F11 เพื่อเต็มจอ

ส่ง **ZIP ต้นฉบับ** ให้เพื่อน แต่ละคนแตกแล้วเปิดใช้งานได้เลย ไม่ต้องลง Node.js ไม่มีบัญชี ไม่มีเซิร์ฟเวอร์ และไม่ต้องใช้อินเทอร์เน็ต หากส่งโฟลเดอร์ที่คุณเคยใช้งานแล้ว โฟลเดอร์ data จะมีข้อมูลของคุณติดไปด้วย

รองรับ Windows 10/11 x64 และการ์ดจอที่รองรับ WebGL2 โปรแกรมรุ่นนี้ยังไม่ได้เซ็น digital signature

## ข้อมูลบันทึกที่ไหน

เมื่อเปิดรุ่น Portable จะสร้าง **data/** ข้างไฟล์ .exe:

- `data/records/workspace.json` ค่าตั้ง, รายการประวัติล่าสุด 300 เซสชัน และเซสชันค้นหาที่ยังค้าง
- `data/records/sessions/<id>.json` ผลแต่ละเซสชัน รวมคะแนนและตัวอย่างเส้นทางการเล็งทุกประมาณ 100ms ไฟล์ผลเดิมจะเก็บไว้แม้พ้นรายการ 300 เซสชัน
- โฟลเดอร์อื่นภายใน `data` เป็นข้อมูลโปรไฟล์ของตัวรันโปรแกรม

เมื่อพักหรือปิดโปรแกรมระหว่างรอบ ระบบจะเริ่มรอบนั้นใหม่เมื่อกลับมา รอบที่ไม่ครบจะไม่ถูกนำมาคิดคะแนน สำรองโดยคัดลอกทั้งโฟลเดอร์ `data` ตอนปิดโปรแกรม หรือใช้ปุ่มส่งออก JSON สำหรับผลแต่ละเซสชัน ข้อมูลไม่ถูกส่งออกอัตโนมัติ

## วิธีเทียบ Sens

ค้นหาสองช่วง ช่วงแรกเทียบประมาณ 71%, 100%, 140% ของ Sens ตั้งต้น ช่วงสองเทียบประมาณ 89%, 100%, 112% ของค่าที่ชนะในช่วงแรก แต่ละค่ามี Flick สองรอบและ Tracking สองรอบ รวม 24 รอบ ใช้เวลาเล่นจริง 8/12/18 นาที ตามระยะรอบ 20/30/45 วินาที บวกเวลานับถอยหลังและเวลาพัก ผู้ใช้ต้องเล่นให้ครบทั้งสองโหมด หากช่วงแรกไม่มีข้อมูลการเล็งที่เพียงพอจะหยุดและแจ้งว่าควรทดสอบใหม่

ทุกค่าทดสอบใช้ seed ของเป้าชุดเดียวกันในแต่ละโหมดและรอบซ้ำ สลับและย้อนลำดับเพื่อช่วยลดอิทธิพลของการวอร์มและความล้า คะแนน Flick รวม hit rate และ accuracy; Tracking ใช้เปอร์เซ็นต์เวลาที่อยู่บนเป้า ค่าเฉลี่ยของทั้งสองโหมดถ่วงน้ำหนัก 70/30 สำหรับ Valorant/CS2 และ 35/65 สำหรับ Apex น้ำหนักเป็นเกณฑ์ของแอปนี้ ไม่ใช่ค่าที่ผู้พัฒนาเกมกำหนด

เลือกจากค่าเฉลี่ยของรอบที่จบจริงและใช้ raw input เท่านั้น หากคะแนนสูสี ผลรอบซ้ำแกว่ง หรือค่าที่ชนะอยู่ขอบช่วง โปรแกรมจะแจ้งให้ทดสอบซ้ำ ไม่มีการรับรองค่าที่ดีที่สุดถาวร ควรเทียบหลายเซสชันและนำไปเล่นในเกมจริง

## Raw input และ FOV

ใช้ Pointer Lock พร้อม `unadjustedMovement: true` เพื่อหมุนกล้องจากการเคลื่อนที่เมาส์ หากระบบไม่รองรับจะอนุญาตเฉพาะโหมดฝึกอิสระด้วย standard input ซึ่งไม่ใช้แนะนำ Sens ควรวัดระยะลากเมาส์ให้หมุนครบ 360° เทียบกับค่า cm/360 ที่แสดงเพื่อตรวจ DPI และความตรงบนเครื่องของตนเอง

ตัวคูณ yaw มาตรฐานที่ใช้: Valorant 0.07, CS2 และ Apex 0.022 องศาต่อ count ที่ Sens 1 สูตร `cm/360 = 914.4 / (DPI × Sens × yaw)` การแปลงข้ามเกมคงระยะหมุนเท่ากันที่ DPI เดียวกัน เป็น Hipfire เท่านั้น ไม่จำลอง ADS, recoil หรือการเคลื่อนที่ตัวละคร

FOV ของ Valorant อ้างอิงแนวนอน 16:9 (103) ส่วน CS2/Apex อ้างอิงแนวนอน 4:3 ตาม Source ป้อน FOV ตามเกมของคุณ สนามจะคำนวณมุมแนวตั้งและใช้ aspect ratio ของหน้าต่าง จึงควรฝึกที่ความละเอียดและ aspect ratio เดิมตลอด บางเกมมี letterboxing หรือการยืดภาพที่แอปนี้ไม่จำลอง

## สำหรับพัฒนา

จากโฟลเดอร์ `sens-lab` ใช้ Node.js 22.12 ขึ้นไป:

```powershell
npm ci
npm start
npm run verify
npm run package
```

รุ่นพัฒนาบันทึกใน `.local-data/` รุ่น Portable อยู่ที่ `release/DaLines-Sens-Lab/` โดยการ package ไม่รวมข้อมูลผู้ใช้งาน สคริปต์สร้างโปรแกรมใช้ Electron runtime ที่ติดตั้งไว้ใน `node_modules/electron/dist` และ bundle Three.js/หน้า UI ในเครื่องทั้งหมด

`npm test` ตรวจสูตรการแปลง, การจัดรอบแบบสมดุล, การคัดข้อมูลที่ไม่ครบ และเกณฑ์แนะนำ Sens ส่วน `npm run verify` เพิ่มการเปิด Electron จริง ตรวจ WebGL/raycast, เขียนอ่าน JSON และกระบวนการครบ 24 รอบด้วยข้อมูลจำลอง พร้อมภาพ `qa-output/desktop.png` ทดสอบการขอ Raw pointer lock และสเกลการหมุนกล้องเพิ่มได้ด้วย `npx electron . --input-test` (จะเปิดหน้าต่างชั่วครู่แล้วปิดเอง) ข้อมูลทดสอบแยกใน qa-output การทดสอบอัตโนมัติไม่แทนการวัด cm/360 ด้วยเมาส์จริงหรือการประเมินความรู้สึกของผู้เล่น

อ้างอิงพฤติกรรมการจับเมาส์: https://developer.mozilla.org/en-US/docs/Web/API/Pointer_Lock_API
